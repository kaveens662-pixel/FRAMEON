✨ About FRAMEON

FRAMEON is a native Android video editor project focused on a premium editing experience, modern visual design, and practical mobile video-editing capabilities.

Inspired by the elegance of frosted glass interfaces and dark cinematic workspaces, FRAMEON aims to combine a clean user interface with powerful Android media technologies.

Designed with a Black + Frosted Glass aesthetic, FRAMEON explores a more refined approach to creating and editing videos on Android.

«Every frame tells a story. Make yours count.»

🎨 Design Philosophy

- 🖤 Dark Cinematic UI — A sleek, distraction-free editing workspace.
- 🧊 Frosted Glass Aesthetic — Translucent surfaces and refined visual details.
- 📱 Mobile-First Experience — An interface designed for Android devices.
- ⚡ Smooth Interactions — Responsive controls and carefully considered animations.
- 🎞️ Timeline-Centered Editing — A foundation for intuitive video-editing workflows.

🚀 Planned Features

The following features represent the project's development goals. Their availability depends on the current implementation.

- 🎬 Video import and preview
- ✂️ Video trimming and clip editing
- 🎞️ Timeline-based editing workflow
- 🎵 Audio and music integration
- 📝 Text and title overlays
- 🖼️ Image and video composition
- 🎨 Filters and visual adjustments
- 📐 Video aspect-ratio presets
- 📤 Video rendering and export
- 🌑 Premium dark-mode interface

⚙️ Getting Started

Prerequisites

- Android Studio
- A compatible JDK
- Android SDK configured in Android Studio
- Gradle wrapper included in the project

Installation

1. Clone the repository

git clone https://github.com/kaveens662-pixel/FRAMEON.git

2. Open the project

Open the cloned project folder in Android Studio.

3. Sync Gradle

Allow Android Studio to download the required dependencies and synchronize the project.

4. Run the application

Connect a compatible Android device or start an emulator, then select Run.
